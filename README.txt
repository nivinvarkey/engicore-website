EngiCore Introduction Website

This is a standalone static website created to introduce the EngiCore desktop application.

How to use:
1. Open index.html in any modern web browser.
2. To host internally, upload index.html to any static web server, SharePoint static hosting solution, GitHub Pages, Vercel, Netlify, or internal IIS server as permitted by your organization.
3. No backend, database, login, or external libraries are required.
