Modules

A focused toolbox for engineering teams.

Each module addresses a specific operational task while following a consistent interface and workflow style.

Dashboard

Home Dashboard

Job-wise release visibility with day, month and custom multi-day filters, plus Today / Yesterday / Week / Month summary cards.

Spool tracking

DC 605 / Status 605

Tracks T-folder based activity, including monthly and job-wise spool counts used in operational reporting.

Reporting

Monthly Report

Combines dashboard differences, DPR activity and Status 605 counts to populate the Shared Service Monthly Report job-wise.

PDF automation

Piping Isometric

Analyzes combined piping-isometric PDFs, groups multi-sheet drawings, then splits and renames files using detected isometric numbers.

Engineering data

Creates standardized Spec Data and Spool Data from JDE and SpecMaster inputs while applying active-spool and status rules.

Workflow highlights

Three high-impact automation areas.

Recent EngiCore versions expanded beyond file utilities into more structured engineering data preparation and reporting.

01 — MONTHLY REPORT

Prepare monthly shared-service reporting faster.

Uses current and previous dashboards, monthly DPR data and T-folder Status 605 counts to calculate job-wise monthly values and fill the established report structure.

02 — PIPING ISOMETRIC

Turn one combined PDF into correctly named isometrics.

Detects piping isometric numbers from title blocks, groups related sheets and produces individual PDFs with consistent drawing-based filenames.

03 — SPEC & SPOOL TAG

Build standardized spool and specification outputs.

Processes JDE and SpecMaster inputs, filters inactive/cancelled records and generates the same structured Spool Data and Spec Data formats used by the team.
